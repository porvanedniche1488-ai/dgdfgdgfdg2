# 🤖 Binance Signals Bot — Telegram-бот з платними сигналами

Бот аналізує **Binance Futures** і раз на 30 хвилин надсилає підписникам готові угоди:
**🟢 ДОВГИЙ/КОРОТКИЙ ЛОНГ**, **🔴 ДОВГИЙ/КОРОТКИЙ ШОРТ** — з монетою, ціною входу,
стоп-лосом, **2 тейк-профітами** та оцінкою шансу спрацювання. Без "очікування підтвердження" —
сигнал генерується миттєво за комплексом індикаторів.

Оплата — **Telegram Stars (⭐️)**, ціну ставиш сам прямо в Telegram командою `/setprice`.
Ключі від Binance **не потрібні взагалі** — бот бере лише публічні ринкові дані.

## ☁️ Деплой на Railway через GitHub (найпростіший спосіб)

### Крок 1. Залий код у GitHub
```bash
cd <тека репо>
git add .
git commit -m "Binance signals bot"
git branch -M main
git remote add origin https://github.com/<твій_юзер>/<ім_я_репо>.git
git push -u origin main
```
⚠️ Репо має бути **приватним** (Settings → Danger Zone → Make private), бо в `config.py` лежить токен бота!

### Крок 2. Підключи Railway
1. Відкрий **https://railway.com/new/github** (або railway.app → New Project → Deploy from GitHub repo).
2. Авторизуй GitHub і дозволь Railway доступ до свого акаунту (або тільки потрібного репо).
3. Обери своє репо → Railway сам знайде `Dockerfile` і збере образ.

### Крок 3. Додай Volume (щоб підписки НЕ зникали після рестарту)
1. У проекті Railway: **права кнопка на сервіс → Attach Volume** (New Volume), Mount Path = `/data`.
   (У Dockerfile вже стоїть `DB_PATH=/data/bot.db` — база ляже саме туди.)
2. Без volume файли на Railway ephemeral — після кожного redeploy база очиститься, тому Volume реально потрібен.

### Крок 4. Перевір змінні оточення (Variables у Railway)
Все вже вшито в `config.py` (токен + admin ID), тому мінімально можна нічого не додавати.
Але **надійніше** прибрати секрети з коду й задати тут:
```
BOT_TOKEN=5994037577:AAFjj03rMKr31vhtB-b2zmF1Q1MZdSYRCag
ADMIN_ID=1813590984
PRICE_STARS=50
SUB_DAYS=30
SCAN_INTERVAL_MIN=30
DB_PATH=/data/bot.db
```
Значення з цих змінних автоматично перевизначають `config.py`.

### Крок 5. Deploy
Натисни **Deploy**. Через ~1–2 хвилини в логах має з'явитися:
```
Scheduler started every 30 min
Health server on port 8080
Application started
```
Відкрий у Telegram свого бота `@HeloypurBot` → `/start` → бот живий! 🎉

Далі будь-які зміни в коді: `git push` → Railway **автоматично** передеплоїть.

### Якщо Railway «засинає» або вбиває процес
Бот тримає HTTP-сервер із `/health` (порт бере з `PORT` Railway). У налаштуваннях сервісу:
- `Networking` → згенеруй публічний domain (не обов'язково, але дає health-check URL).
- Restart Policy вже стоїть `ALWAYS` у `railway.toml`.
- На безкоштовному плані Railway може обмежувати ресурс — для продакшну бери Hobby ($5/міс), бот їсть ~100 МБ RAM.

## 🖥 Запуск локально (для тестів)

### 1. Створи бота і візьми ключ (токен)
1. У Telegram знайди **@BotFather** (синя галочка).
2. Надішли йому `/newbot`, придумай назву (напр. `My Signals`) та username, що закінчується на `_bot` (напр. `my_signals_bot`).
3. BotFather відповість рядком типу: `123456789:AAH4x...abc` — **це і є токен (ключ) бота**. Зберігай його в секреті!
4. Там же в BotFather: `/setdescription`, `/setcommands` — для краси:
   ```
   start - Почати
   help - Довідка
   buy - Купити пропуск ⭐️
   status - Мій доступ
   signal - Сигнал зараз
   ```

### 2. Дізнайся свій Admin ID
Напиши боту **@userinfobot** — він покаже твой числовий ID (напр. `712345678`).

### 3. Впиши все в `config.py`
```python
BOT_TOKEN = "123456789:AAH4x...abc"   # токен від BotFather
ADMIN_ID  = 712345678                  # твій ID
```
(або через змінні оточення `BOT_TOKEN`, `ADMIN_ID` — так безпечніше)

### 4. Встанови залежності та запусти
```bash
pip install -r requirements.txt
python bot.py
```
Готово — бот працює. Для постійної роботи постав на VPS і запускай через `systemd` або:
```bash
nohup python bot.py > bot.log 2>&1 &
```

## 💰 Як працює оплата (Telegram Stars)

Це **вбудована оплата Telegram** — не треба жодних ексчейнджів чи платіжних систем:
- Користувач натискає `/buy` або кнопку «Купити пропуск».
- Telegram показує рахунок у ⭐️ **Stars** (зірки), які юзер купує прямо в додатку.
- Після оплати бот отримує `successful_payment` і **миттєво активує підписку** на 30 днів.
- Гроші йдуть на твій акаунт через Telegram; вивести можна через **Fragment** (конвертація Stars) — перевіряй актуальні умови в @BotFather → `/mybots` → Payments.

⚠️ Щоб Stars працювали, бот має бути створений через BotFather і мати увімкнену комерцію — для XTR (Stars) provider token НЕ потрібен, у коді вже `provider_token=""`, `currency="XTR"`.

### Команди адміна (працюють тільки для твого ADMIN_ID):
| Команда | Дія |
|---|---|
| `/setprice 50` | Поставити ціну пропуску в 50 ⭐️ (міняється на льоту!) |
| `/setdays 30` | Тривалість пропуску в днях |
| `/grant <uid> [днів]` | Видати доступ вручну (напр. другу) |
| `/revoke <uid>` | Забрати доступ |
| `/scan` | Примусово просканити ринок і розіслати |
| `/broadcast Привіт!` | Розсилка всім активним |
| `/stats` | Скільки юзерів / платників |

## 🧠 Як рахуються сигнали (без очікувань)
Для топ-120 монет за об'ємом рахується скор по 6 факторах:
1. **EMA9/EMA21** — напрямок тренду
2. **Open Interest + рух ціни** — чи заходить реальний грошовий потік
3. **Спайк обсягу** — імпульсність
4. **RSI(14)** — перепродано/перекуплено (пошук розворотів)
5. **Long/Short Ratio натовпу** — граємо *проти* перевантаженого натовпу
6. **Фандинг** — перегрітий ринок шортимо, негативний фандинг — лонг

- Скор ≥ 6 → **КОРОТКИЙ** сигнал (scalp: тісні SL/TP); скор 3–6 → **ДОВГИЙ** (swing: ширші рівні).
- Рівні рахуються від **ATR(14)** — адаптуються під волатильність кожної монети.
- «Шанс» = функція сили сигналу (55–97%).

Налаштувати гостроту можна в `analyzer.py`: `threshold = 3.0`, множники `sl_mult/tp1_mult/tp2_mult`.

## ❓ Про «ключі»
- **Токен бота** — див. пункт 1 вище (BotFather → `/newbot`). Це єдиний "ключ", який потрібен.
- **API-ключ Binance НЕ потрібен** — усі дані (свічки, OI, funding, long/short ratio) публічні.
- **Provider token для оплати НЕ потрібен** — Telegram Stars працюють без нього.

## ⚠️ Дисклеймер
Сигнали — це статистична ймовірність, не гарантія прибутку. Не фінансова порада.
